About Static Grave

Static Grave Productions is an independent game studio built around a simple belief:

Imagination deserves the effort required to turn it into something worth experiencing.

We create worlds and experiences with an emphasis on creativity, craft, integrity, and respect for the player.

We are not interested in chasing ideas simply because they are easy to produce. We want to follow them where they deserve to go and give them the care necessary to become what they should be.

«The Player Is Worth the Effort.»
